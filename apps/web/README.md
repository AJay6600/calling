# web

Organization-facing dashboard for the AI Outbound Calling SaaS Platform — leads, campaigns, call logs, billing, and settings.

## Local development

### Start server

```
yarn nx run web:serve
```

## Testing

### Linting/Static testing

```
yarn nx run web:lint
```

### Unit/integration Testing

```
yarn nx run web:test
```
